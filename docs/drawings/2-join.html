2. Join

Peter asks Vibe to join. Vibe connects and starts the loop.

In words

  1. Peter says "join the meeting" and gives the agent link.
  2. Vibe uses the skill to write .vibe/agent-link.
  3. Vibe gets the agent link from Live Notes.
  4. Live Notes sends back connection instructions.
  5. Vibe publishes a page as vibe-agent.
  6. Vibe schedules the loop with cron, every 30 s.
  7. Vibe tells Peter: "I follow the meeting".
  8. The turn ends, and the hook starts to wait.
What is tested. Only the hook has run in Vibe. The skill, the loop next to the hook, and leaving are written but not tried.
